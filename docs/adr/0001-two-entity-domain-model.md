# 领域模型采用「生成配方 + 生成记录」两实体

一次 AI 图片/视频生成中，提示词、种子、参数属于这一次运行，而可复用的生成配置应被单独管理。我们决定拆为两类实体：生成配方（可复用的生成配置，形态可以是 ComfyUI 工作流 JSON、参数预设或提示词模板）与生成记录（一次实际生成，携带当次提示词/参数/产物/时间，**可选地**关联一个配方——可灵/Runway 等云端工具没有工作流文件，记录独立成立）。产物（图片/视频文件）挂在生成记录下而非独立资产。"配方关联可选"与"泛化为配方"两点是后续调研中修订的：原设计称「工作流定义」且必填关联，无法覆盖云端工具与纯收藏提示词的场景。备选方案「每次生成存一条含工作流附件的完整记录」被否决，因为它无法支撑「同一配方的复现与使用统计」。词汇见 CONTEXT.md。
